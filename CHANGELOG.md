# Changelog

## Unreleased

## v0.1.3 — 2026-11-21

### Fixed

- Fix GIF pause for Giphy, Tenor, and Imgur in desktop webviews that support it.
- Connect Read Aloud to your configured speech service.

## v0.1.2 — 2026-11-21

### New

- Get notified about desktop updates on macOS and Windows and install them from IRCord.
- Open the IRCord window, check for updates, or quit from the system tray or Mac menu bar.

### Improved

- Check that a server runs IRCord before opening sign-in, and see whether you can create an account there.
- Remember the size and position of the chat window and bring it forward when IRCord opens again.

### Fixed

- Make the IRCord icon fill its space in the macOS Dock.

## v0.1.0 — 2026-11-21

### New

- Install IRCord Desktop on Apple Silicon Macs, Windows x64, and Debian-based Linux x64 systems.
- Open the bundled chat interface as soon as the app starts.
- Choose the public IRCord server or a self-hosted server on first launch.
- Receive native notifications while IRCord Desktop is running.

### Improved

- Move and control the IRCord window from the top of the app.
- Stay signed in between launches and switch IRCord servers from the app.
- Copy messages, links, drafts, and code to the system clipboard.

### Fixed

- Connect to a local server using an HTTP address with `localhost`.
- Install the certificates needed to connect to HTTPS servers on Debian and Ubuntu.
